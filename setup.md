# Dialogus AI Blog Generator — Setup Guide

## Prerequisites

- Node.js 18.18.0 or higher
- Your existing Dialogus Next.js app running
- A Sanity project with members already added
- API keys for Anthropic (Claude) and Google AI (Imagen 3)

---

## Step 1: Get Your API Keys

### Anthropic (Claude) API Key

1. Go to [console.anthropic.com](https://console.anthropic.com/)
2. Sign up or log in
3. Navigate to **API Keys**
4. Click **Create Key**
5. Copy the key (starts with `sk-ant-...`)

### Google AI (Imagen 3) API Key

1. Go to [aistudio.google.com](https://aistudio.google.com/)
2. Sign in with your Google account
3. Click **Get API Key** in the top-left
4. Create a new key or use an existing one
5. Copy the key

### Sanity Write Token

1. Go to [manage.sanity.io](https://www.sanity.io/manage)
2. Select your Dialogus project
3. Navigate to **API** → **Tokens**
4. Click **Add API Token**
5. Name it something like `Blog Generator Write`
6. Set the permissions to **Editor**
7. Click **Save** and copy the token

### Session Secret

Generate a random secret for signing session cookies. Run this in your terminal:

```bash
openssl rand -hex 32
```

Copy the output.

---

## Step 2: Configure Environment Variables

Open (or create) the `.env.local` file in the `dialogus-next/` directory and add these variables:

```env
# --- Existing variables (should already be present) ---
NEXT_PUBLIC_SANITY_PROJECT_ID=your_sanity_project_id
NEXT_PUBLIC_SANITY_DATASET=production
NEXT_PUBLIC_SANITY_API_VERSION=2024-01-01

# --- New variables for the Blog Generator ---

# Anthropic Claude API key for content generation
ANTHROPIC_API_KEY=sk-ant-your-key-here

# Google AI API key for Imagen 3 image generation
GOOGLE_AI_API_KEY=your-google-ai-key-here

# Sanity write token (Editor role) for publishing articles
SANITY_WRITE_TOKEN=your-sanity-write-token-here

# Random secret for signing session cookies (output of openssl rand -hex 32)
SESSION_SECRET=your-64-char-hex-string-here
```

**Important:** Never commit `.env.local` to version control. It should already be in your `.gitignore`.

---

## Step 3: Create Your Sanity Personal Token (for Login)

Each admin user needs a personal Sanity API token to log in to the dashboard.

1. Go to [manage.sanity.io](https://www.sanity.io/manage)
2. Select your Dialogus project
3. Navigate to **API** → **Tokens**
4. Click **Add API Token**
5. Name it something like `Your Name - Admin Login`
6. Set the permissions to **Viewer** (minimum required) or **Editor**
7. Click **Save** and keep the token handy — you'll use it to log in

This is different from the `SANITY_WRITE_TOKEN` above. The personal token identifies *who* is logging in. The write token is used server-side for publishing.

---

## Step 4: Start the Development Server

```bash
cd dialogus-next
npm run dev
```

---

## Step 5: Access the Dashboard

1. Open your browser and go to: `http://localhost:3000/admin/login`
2. Enter your Sanity Personal API Token from Step 3
3. Click **Sign In**
4. You'll be redirected to the Blog Generator dashboard at `/admin/generate`

## Using the Dashboard

### Generating an Article

1. **Topic** (required) — Enter what you want the article to be about. Be specific for better results.
   - Example: `India's new digital privacy bill and its impact on tech startups`
2. **Instructions** (optional) — Guide the AI on tone, angle, or specific points.
   - Example: `Focus on the economic impact. Mention the GDPR comparison. Keep a critical tone.`
3. **Category** — Select from your existing Sanity categories
4. **Author** — Select from your existing Sanity authors
5. Click **Generate Article**

### Reviewing and Editing

After generation, you'll see the full article with all fields editable:

- **Title** — Edit the headline. The slug auto-updates when you change the title.
- **Slug** — The URL path (`/insights/your-slug`). Auto-generated but editable.
- **Description** — SEO summary with a live character counter (max 200).
- **Body** — Markdown editor with Write/Preview tabs. Edit raw markdown or preview the rendered output.
- **Cover Image** — Auto-generated by Imagen 3. You can:
  - Edit the image prompt and click **Regenerate Image**
  - Click **Upload Custom** to use your own image

### Regenerating with Feedback

1. Click the **Regenerate** button in the bottom bar
2. Type your feedback (e.g., "Make the introduction shorter", "Add a section about enforcement")
3. Click **Regenerate Content**
4. The AI revises the article based on your feedback while preserving what works

### Publishing

- **Publish** — Creates a live article on your website immediately
- **Save as Draft** — Creates a draft in Sanity Studio for further editing
- **Start Over** — Resets everything and returns to the input form

After publishing, you'll see links to:
- View the article on your website (`/insights/{slug}`)
- Edit the article in Sanity Studio

## Deployment (Netlify)

When deploying to Netlify, add the same environment variables from Step 2 to your Netlify project:

1. Go to your Netlify dashboard → Site settings → Environment variables
2. Add each variable:
   - `ANTHROPIC_API_KEY`
   - `GOOGLE_AI_API_KEY`
   - `SANITY_WRITE_TOKEN`
   - `SESSION_SECRET`
3. Redeploy your site

**Note:** The `/api/generate-blog` route may take 10-15 seconds to generate content. Netlify's default function timeout is 10 seconds (26 seconds on Pro plan). If you hit timeouts, consider upgrading your Netlify plan or using the dashboard locally during development.

---

## Security Notes

- The admin dashboard is protected by Sanity-based authentication. Only members of your Sanity project can access it.
- Session cookies are signed with HMAC-SHA256 using `SESSION_SECRET`. They expire after 7 days.
- The `SANITY_WRITE_TOKEN` is server-side only — it is never exposed to the browser.
- All AI API keys are server-side only — they are never sent to the client.
- The middleware protects `/admin/generate/*`, `/api/generate-blog`, `/api/generate-image`, and `/api/publish-blog`.
- The login page at `/admin/login` is publicly accessible (so users can enter their tokens).

## Troubleshooting

### "Invalid token or you are not a member of this Sanity project"
- Make sure your personal token is valid and has not expired
- Verify you are listed as a member in manage.sanity.io → your project → Members

### Categories/Authors dropdowns are empty
- Make sure `SANITY_WRITE_TOKEN` is set and has at least Viewer permissions
- Verify you have `category` and `author` documents in your Sanity dataset

### Image generation fails
- Imagen 3 may not be available in all regions. Check the Google AI Studio console for errors.
- Make sure your `GOOGLE_AI_API_KEY` has the Generative Language API enabled

### Content generation fails
- Check that `ANTHROPIC_API_KEY` is valid and has credits
- The API returns a 429 error if you've hit rate limits

### Session expired
- Log out and log in again with your Sanity token
- Sessions last 7 days. After that, re-authentication is required.
